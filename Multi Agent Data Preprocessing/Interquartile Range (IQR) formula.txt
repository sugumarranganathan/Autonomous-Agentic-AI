Quick Formula Cheat Sheet
-----------------------

| Formula                            | Description          |
| ---------------------------------- | -------------------- |
| **IQR = Q3 − Q1**                  | Interquartile Range  |
| **Lower Bound = Q1 − (1.5 × IQR)** | Minimum normal value |
| **Upper Bound = Q3 + (1.5 × IQR)** | Maximum normal value |
| **Value < Lower Bound**            | Lower outlier        |
| **Value > Upper Bound**            | Upper outlier        |


==========

Easy way to remember

Step 1: Find Q1 (25%)

Step 2: Find Q3 (75%)

Step 3: IQR = Q3 − Q1

Step 4: Lower = Q1 − 1.5 × IQR

Step 5: Upper = Q3 + 1.5 × IQR

Step 6: Any value outside these limits is an Outlier.

=========

This is the standard IQR method used in data preprocessing and machine learning to identify unusually low or high values in numerical data.

===========

The Interquartile Range (IQR) formula is:

Formula
IQR = Q3 − Q1

Where:

Q1 (First Quartile) = 25th percentile (25% of the data is below this value)
Q3 (Third Quartile) = 75th percentile (75% of the data is below this value)


Lower Bound Formula
Lower Bound = Q1 − (1.5 × IQR)


Upper Bound Formula
Upper Bound = Q3 + (1.5 × IQR)


Outlier Rule

A value is an outlier if:

Value < Lower Bound

or

Value > Upper Bound
Example

Dataset:

10, 12, 15, 18, 20, 22, 25, 28, 30

=========


Step 1: Find Quartiles
Q1 = 15
Q3 = 28

======

Step 2: Calculate IQR
IQR = Q3 − Q1
     = 28 − 15
     = 13

=========

Step 3: Calculate Lower Bound
Lower Bound = Q1 − (1.5 × IQR)

             = 15 − (1.5 × 13)

             = 15 − 19.5

             = -4.5

========

Step 4: Calculate Upper Bound
Upper Bound = Q3 + (1.5 × IQR)

             = 28 + (1.5 × 13)

             = 28 + 19.5

             = 47.5

===========

Final Result
------------

IQR = 13

Lower Bound = -4.5

Upper Bound = 47.5

============

Any value:

Less than -4.5 → Outlier
Greater than 47.5 → Outlier
